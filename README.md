# DJITAL ARENA 07 BY FADI — Advanced GitHub Pages Store

هيكل المشروع أصبح مثل مستودع GitHub احترافي ومقسّم:

```text
digital-arena/
├── index.html
├── style.css
├── script.js
├── data.js
├── README.md
├── GITHUB_PAGES.md
└── assets/
    ├── catalog-cover.png
    └── product-*.svg
```

## المزايا
- تصميم Gaming احترافي ومتجاوب.
- فصل HTML / CSS / JavaScript / بيانات المنتجات.
- 60 منتجاً وخدمة من الكتالوج الذي أرسلته.
- صور محلية لكل منتج، مع صورة الكتالوج الأصلية التي أرسلتها داخل المشروع، لذلك الموقع لا يعتمد على روابط صور خارجية.
- بحث فوري.
- تصفية حسب القسم.
- ترتيب المنتجات.
- نافذة تفاصيل المنتج.
- سلة مشتريات محفوظة في LocalStorage.
- طلب كامل عبر WhatsApp: 0665565242.
- Dark / Light mode.
- جاهز لـ GitHub Pages.

## تعديل المنتجات
كل بيانات المنتجات موجودة في `data.js`.
يمكنك تعديل:
- الاسم
- القسم
- المواصفات
- الوصف
- السعر
- صورة المنتج

## النشر
ارفع جميع الملفات إلى Repository واحد، ثم:
`Settings → Pages → Deploy from a branch → main → / (root)`.


## صور المنتجات المرفقة
تمت إضافة صورة الكتالوج التي أرسلها صاحب المتجر إلى `assets/catalog-cover.png`، مع قصاصات محلية لصور الفئات والمنتجات الظاهرة فيها. المنتجات الأخرى تحتفظ بصور محلية مخصصة لها داخل مجلد `assets/`.
