# Digital Arena

متجر إلكتروني Static جاهز للرفع على GitHub Pages.

## التشغيل
- افتح `index.html` مباشرة في المتصفح، أو ارفع المشروع إلى GitHub.
- فعّل GitHub Pages من إعدادات المستودع.
- عدّل مصفوفة `products` داخل `index.html` إذا أردت تغيير الصور أو الأسعار أو المواصفات.
- رقم واتساب داخل الموقع: `0665565242`.

## ملاحظة الصور
الصورة التي أرسلها صاحب المتجر محفوظة محلياً في `assets/catalog-cover.png`.
صور بطاقات المنتجات الحالية صور توضيحية فئوية من Unsplash ويمكن استبدال روابطها بصور المنتجات الحقيقية.
